# Notebooks

Use this directory for reproducible analysis notebooks.

Suggested sequence:

1. `01_eda.ipynb` — data quality, distributions and conversion analysis
2. `02_feature_engineering.ipynb` — feature creation and leakage checks
3. `03_model_training.ipynb` — baseline and advanced models
4. `04_model_evaluation.ipynb` — metrics, threshold tuning and explainability

Do not commit confidential customer data or generated PII into notebooks.
